# LivePilot

LivePilot is a lightweight companion dashboard designed to sit beside a TikTok Live session.

## V1 features

- Live session timer
- Manual viewer / like / gift / comment counters
- Like and gift goals
- Run-of-show checklist
- Engagement prompt generator
- Persistent live notes
- Manual comment/question queue
- Mobile-friendly responsive UI

## Current integration status

V1 is intentionally a standalone companion app. It does not yet pull TikTok Live data directly. Future versions can explore official or permitted integrations for live events, analytics, overlays and creator workflows.

## Run locally

Open `index.html` in a browser.
